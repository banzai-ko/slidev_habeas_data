# Presentación Slidev: Protección de datos personales y hábeas data

## Requisitos
- Node.js 20 o superior (recomendado)
- npm

## Ejecutar en modo presentación

```bash
npm install
npm run dev
```

## Exportar a PDF o PowerPoint

```bash
npm run export:pdf
npm run export:pptx
```

La exportación a PPTX requiere las dependencias y el navegador compatibles con Slidev. El PPTX exportado puede tener limitaciones de edición según los elementos utilizados.

## Contenido
La presentación está basada en el texto proporcionado por el usuario. Los casos jurisprudenciales se resumen tal como aparecen en ese material; no se realizó una verificación jurídica independiente.
